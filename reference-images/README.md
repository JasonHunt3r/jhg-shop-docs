# Reference Images

Photos of physical things — tool cases, machine labels, hardware, stock, cut
results — dropped here so a session can read what is actually in the shop
instead of inferring it from a doc that may be a fossil.

## How it works

**Drop new images in this folder.** Anything sitting at the top level is
unread: a session should look at it, pull out whatever matters, and write that
into the doc that owns the subject — not leave the fact living in a photo.

**`transcribed/` is for images whose content is now in the docs.** That is the
whole criterion for moving one down: the durable record exists elsewhere, and
the image is kept only as the evidence behind it. Nothing here is required
reading — if a rule depends on an image nobody opens, the rule is in the wrong
place.

The split matters because an unread photo and a read one look identical on
disk. Top level means *someone still has to look at this*.

## Naming

Camera names (`IMG_3896.jpeg`) say nothing. Rename on filing, following the
same convention as the shop files — lowercase alphanumeric, dash and
underscore, no periods except the extension:

```
bit1_spws2lx6_22_case.jpeg      what it is, then what identifies it
```
